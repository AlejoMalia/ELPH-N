## 2 · El hallazgo central · **las dos exigencias de COMPRIMIR se excluyen**

**B2 / D-373, MEDIDO:** *encoger un 20 % sale gratis; **un 1 % de desorden local rompe el contrato**.*
Luego lo que cuenta **no es cuánto encoge, sino cuánto encoge DISTINTO cada tejido**:

| tejido | agua | encogimiento lineal |
|:--|--:|--:|
| riñón | 79 % | 1,86× |
| músculo | 75 % | 1,75× |
| hueso | 22 % | 1,20× |
| **adiposo** | **15 %** | **1,17×** |

| `f` agua retirada | agua residual | ¿vidrio? | desajuste | ¿elástico? |
|--:|--:|:--|--:|:--|
| 0,30 | 2,10 g/g | no | 6,9 % | **sí** |

> **El vidrio exige `f` ≥ 0,967. Sin homogeneizar, la elasticidad exige `f` ≤ 0,57: no se solapan, `N` = 2,55.**
>
> **Y la clave está en el «mientras»: el conflicto existe mientras la grasa tenga 15 % de agua y el músculo
> 75 %.** No es química: es composición — **y la composición se puede cambiar** (§3).

**Y el contrato manda por el MÁXIMO, nunca por la media:** basta una interfaz grasa/músculo, y el cuerpo está
lleno de ellas.

## 3 · La palanca, y la dice nuestro propio contrato

El desajuste existe **porque el agua está repartida de forma desigual**. Igualarla exige **quitar el lípido**.
Y el contrato corporal (D-521) dice que **el tejido adiposo es COMPOSICIONAL: no tiene dirección** — es el
tejido de paso de Krogh más grosero (`s/2` = 950 µm), el más tosco del cuerpo.

> **Si el lípido no lleva dirección, no hay que conservarlo: se declara y se repone, igual que el agua.**

**Con la grasa delipidada, el siguiente valor atípico es el hueso (22 % de agua) — y el pulpo lo nombra: el
límite de un cuerpo blando lo fija su parte rígida** (D-570). El hueso se parte igual:

| componente del hueso | contrato | ¿viaja? |
|:--|:--|:--|
| **matriz de colágeno** | **GEOMÉTRICO** — lleva dirección | **sí** |
| **hidroxiapatita** | **COMPOSICIONAL** — es material | **no: se declara y se repone** |

Los **osteoclastos** ya lo hacen con HCl, y la matriz desmineralizada (DBM) es un producto clínico real.

```
cuerpo tal cual (grasa 15 %, hueso 22 %)   desajuste 38,2 %   N = 2,55   falla
delipidado + desmineralizado (65-79 %)     desajuste 14,6 %   N = 0,97   PASA
```

**Tercera aplicación de la misma regla —agua, lípido, mineral—: lo que no lleva dirección no se envía ni se
mide, se declara** (regla 291).
